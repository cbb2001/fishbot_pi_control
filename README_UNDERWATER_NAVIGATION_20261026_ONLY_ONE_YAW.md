# 水面调向、单航段锁定 yaw 偏差的水下导航

入口：`scripts/run_underwater_navigation_20261026_only_one_yaw.py`。
配套接口：`control/runtime/underwater_navigation_20261026_only_one_yaw.py`（参数、固定偏差尾鳍 PI）和 `control/runtime/underwater_navigation_session_20261026_only_one_yaw.py`（阶段、点表、采集会话）。原入口及接口保留。

## 运行与调参

在项目根目录、原项目 Python 环境中运行：

```powershell
# 全模拟，包括模拟水面航向收敛；不访问硬件
python scripts/run_underwater_navigation_20261026_only_one_yaw.py --dry-run --t1 0 --t2 1 --t3 15 --t4 2

# 单点；t4=t3，中途不上浮重新定位
python scripts/run_underwater_navigation_20261026_only_one_yaw.py --x-d 10 --y-d 10 --h0 .3 --t3 120 --t4 120 --delta-yaw 10 --confirm MOVE

# 多点：每个 --waypoint 是 X Y H T，T 为该目标的最长执行秒数或 NULL
python scripts/run_underwater_navigation_20261026_only_one_yaw.py --waypoint 10 10 .3 30 --waypoint 15 10 .4 40 --waypoint 15 15 .3 NULL --t3 180 --t4 10 --confirm MOVE

# 显式单点：最后/唯一目标的 T 必须为 NULL
python scripts/run_underwater_navigation_20261026_only_one_yaw.py --waypoint 10 10 .3 NULL --t3 120 --t4 10 --confirm MOVE

# 仅采集诊断，不初始化 PWM
python scripts/run_underwater_navigation_20261026_only_one_yaw.py --no-servo --t3 60
```

原脚本的单点和运动参数全部保留。`--waypoint X Y H T` 可重复，四个参数分别为水平坐标、目标水深（米，向下为正）和该目标的最长执行时间（秒）。`T` 接受不区分大小写的 `NULL`，或严格大于 0 的有限数值；最后一个目标（包括只有一个目标时）的 `T` 必须为 `NULL`。原三元点表需要补上第四项，不会自动猜测目标超时时间。

`--delta-yaw` 复用原 `NavigationConfig.delta_yaw`（当前配置 10°），规定下潜前角差容差，范围 `0 < delta_yaw < 45`。尾鳍的大角差阈值仍为原来的 45°。

未提供点表时使用 `--x-d / --y-d / --h0` 或 YAML 中对应默认值，生成 `(x,y,h,NULL)` 单点。提供点表时，以点表的坐标和各自水深为实际目标；单点参数不覆盖点表。`--delta-s` 仍为水平到点容差，判据为距离严格小于该值。每个目标深度必须大于 0 且低于 `safety.max_depth_m`，XY 必须位于基站矩形范围内；全部目标及其时间参数在启动采集/PWM 前校验。

默认继续读取 `config/robot.yaml` 中的 `underwater_navigation_20261026` 和 `surface_navigation_20261010`。也可在同一 YAML 增加新版本专用覆盖段，例如：

```yaml
underwater_navigation_20261026_only_one_yaw:
  t3: 180
  t4: 10
  delta_yaw: 10
  waypoints:
    - [10, 10, 0.3, 30]
    - [15, 10, 0.4, 40]
    - [15, 15, 0.3, null]
```

优先级：命令行 > 新版专用段 > 原版水下段/水面段。点表仅使用 `only_one_yaw` 专用段或命令行，不继承另一入口的点表；YAML 中建议用原生 `null` 表示 `NULL`。采样率、传感器超时、舵机配置、日志队列等仍从原共享位置读取。新专用段无需复制整套配置；若覆盖 `ekf`，需给出完整 EKF 子配置，规则与原配置加载器一致。

## 阶段与时间

1. `t1` 人工放置、`t2` 静止标定沿用原流程。初始 UWB 先累计一组有效帧建立基准，再启动 PWM 归中；收到归中回执后重新累计一组有效帧，作为首次定位。
2. `align`：根据有效平均 UWB XY 和当前目标计算目标方位。胸鳍保持归中，尾鳍复用原转向动作：大角差时同侧 30°/20°（受配置及机械限位约束），小角差时原 PI 摆动。此阶段仍用标定后的 IMU yaw 判断调向进度；单个 UWB 标签的位置无法单独测得鱼头朝向。
3. 角差进入 `delta_yaw` 后取消调向动作并归中，等待 PWM 回执及采集时间晚于回执的 IMU 航向样本，再检查水面角差。若又超出容差，继续水面调向；仍在容差内才锁定剩余 yaw 偏差、启动胸鳍下潜。锁定的不是最初的大角差。
4. `navigate`：胸鳍按当前目标水深执行原定深 PI/两半程动作；尾鳍仅使用本航段锁定偏差。不会用实时 IMU yaw 或 EKF XY 重算目标角差，也不会用水下估计位置触发切点。`ki` 非零时仍对固定偏差积分并限幅，因此**误差固定不等于尾鳍摆幅固定**。IMU 继续用于健康监测、原 EKF 估计和日志；这些估计不反馈给航向或到点判断。
5. `t4` 到期后归中，执行原胸鳍全行程上浮动作。任意一路新鲜有效 UWB 距离即可触发停止上浮并归中；归中回执后重新累计合格四路帧，平均定位，再切点/水面调向/锁定偏差/下潜。部分 UWB 只能停止上浮，不能用于定位、切点或更新偏差。

| 参数 | 新版含义 |
|---|---|
| `t1` / `t2` | 人工放置 / 固定静止标定时间，与原版一致 |
| `t3` | **首次水面调向开始**起的总任务时间，包含全部调向、下潜、上浮、归中、等 UWB、最终点保持；切点或重定位不重置 |
| `t4` | 每次开始下潜/导航起的最长时间，包括该航段到点保持；水面调向不占本段 t4 |
| 每个目标的 `t` | 从该目标被选为当前目标开始计时，包含调向、导航、上浮和等待有效 UWB；同一目标的重新定位或 t4 周期不会重置。`NULL` 表示永不自动切到下一目标 |

`t3` 始终拥有最高截止优先级，包括与目标超时同时发生的情况。`t4 >= t3` 时不触发定时上浮；但多目标中某个数值 `t` 到期，仍可能触发切点所需的上浮重新定位。若希望整个任务中途不上浮，使用单点 `t=NULL` 且 `t4>=t3`。

没有中途有效 UWB 定位就不会确认途中目标到达，但数值 `t` 到期仍会切换目标索引。上浮/重新取数沿用原规则，无有效数据时继续上浮或等待，直到 t3、外部停止或故障；等待期间数值 `t` 也继续计时。不会用旧位置或上一目标的锁定角差放行新目标下潜。首次定位仍有原 `fix_timeout_s` 限制。水面始终无法调到容差内时，也由 t3 结束任务。

## 多目标与最终保持

每次合格水面平均定位只用 XY 与当前目标比较；水面观测深度为 0，目标 H 用于随后定深，不用于水面到点距离。

中间目标的 `t` 为数值时，满足以下任一条件就切换到下一目标：有效水面 UWB 定位确认进入 `delta_s` 范围，或当前目标执行时间达到 `t`。到点切换可用同次有效定位给新目标导向；若相邻多个有限时目标同时处于范围内，则按顺序跳过，遇到 `t=NULL` 的目标即停止切换。新目标从切换时刻重新计时，总时间 t3 不重置。

数值 `t` 到期时若仍在水下，立即更新目标索引、取消旧航段动作并上浮；收到新的有效平均 UWB 后，先水面调向、再锁定角差并下潜。若到期时正在水面调向，则先归中，再按原规则重新接收一组有效 UWB。若已经处于上浮或 UWB 接收阶段，只更换当前目标，继续现有上浮/接收过程，不反复重启归中或清空正在累计的帧。

`t=NULL` 表示持续以该点为目标，到达范围内也不切换下一点；因此中间点设为 `NULL` 后，后续目标不会自动执行。围绕该点运行沿用原控制逻辑：范围内尾鳍归中、胸鳍定深，周期上浮后若有效 UWB 显示漂出范围，再重新导向该点；这里没有新增固定半径的绕圆轨迹。

最终点进入范围后不再切换目标，尾鳍保持归中，胸鳍继续原压力定深直到 t3。原 t4 上浮周期仍保留：后续有效 UWB 若显示漂出最终点范围，则重新水面调向并导航回该点；否则继续保持。水下估计漂移不会解除保持。

## UWB、执行器和日志

直接复用原 `AcceptedUWB`、解码器、`UnderwaterScheduler`、PWM 执行器、压力漂移标定和安全监测。有效 UWB 规则保持一致：只接受同条 mc 报文的完整四路正有限距离，按帧 ID 去重、检查阶段采集边界/年龄/相对上一组均值的跳变；累计 `uwb_average_frames`（默认 5）帧，先逐路平均测距再解算 XY。归中前后不混帧，重新定位时清零航段积分，保留启动标定。胸鳍完成回执才推进 b1/b2，取消动作不算完成，跨阶段保留 b2 交替。

默认日志写入 `logs/underwater_navigation_20261026_only_one_yaw/`。保留原日志和关停结果，增加：

- `surface_alignment_started`：水面定位、目标方位和调向起点。
- `yaw_frozen`：真正锁定的角差、对应水面航向、定位时间与归中回执。
- `tail_control`：`surface_live` / `surface_frozen` 标识偏差来源及 PI 输出。
- `waypoint_started` / `waypoint_completed`：当前目标启用时间、时限和实际执行秒数；同一目标重新定位不会重新启动目标计时。
- `waypoint_reached` / `waypoint_changed`：有效 UWB 确认到点和切换记录，切换原因区分 `reached` / `timeout`（索引从 0 开始）。
- 状态/结果中的目标索引、四元目标、当前目标到达状态、最终点状态、锁定角差；状态另含当前点已用/剩余秒数。距离明确是最后有效水面 UWB 到当前目标的距离，非实时水下距离；超时切点后尚未重新定位时为空。
- `imu_filtered.yaw_updated=false` 表示水下不更新航向滤波；其中 `yaw_deg` 为保留值，不应当作实时 yaw，原始 IMU 数据仍正常记录。

正常 t3 结束时沿用归中、保持中位 PWM、关闭输出的清理流程；`--no-servo` 保留原采集诊断模式，不执行调向/下潜/切点。模拟仅检查软件时序，不模拟真实航迹或水动力；实际航向调整和导航精度需要水池验证。
