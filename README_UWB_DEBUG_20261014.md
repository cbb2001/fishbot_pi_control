# 单基站 A0 UWB 实时诊断

在树莓派项目根目录运行，先停止占用同一 UWB 串口的导航或采集程序：

```bash
python scripts/test_uwb_20261014.py
```

默认持续采集，Ctrl+C 或 SIGTERM 停止并保存摘要。指定采集时长：

```bash
python scripts/test_uwb_20261014.py --t 60
```

脚本不创建舵机控制器、不写 PWM，也不发送回中指令；仅开启 UWB，不启动 IMU、深度、电源或相机。它不会关闭其他进程或此前遗留的 PWM 输出，因此应在原运动程序正常退出后启动。

## CRLF逐行采集方式

测试程序与正式导航共用 `SensorManager → UWBWorker → RingBuffer`，测试入口通过配置仅开启 UWB。读取同一份 `config/robot.yaml` 的 `sensors.uwb` 配置，包括 `port`、`baudrate`、`serial_timeout_s`、`buffer_size`。缺省端口 `/dev/ttyAMA0`、波特率 115200、串口超时 0.2 秒；公共接口 `read_uwb_chunk` 使用 `read_until(b'\r\n', size=4096)`，遇到行尾立即返回，4096仅为异常超长输入的读取上限，不是固定报文长度。空读记录仍按0.5秒间隔限频，串口异常后关闭并重试。所有使用 `SensorManager` 的实际 UWB 采集及独立录制入口均采用这一公共读取接口。

使用 `raw_hex` 还原字节并以 `\r\n` 拼帧。超时返回的半帧以及普通空读前的半帧均保留，支持 `\r` 和 `\n` 分属两次读取；串口错误或缓冲序号缺口后才清除半帧。每个读取结果在返回时记录时间戳，正常一行一个时间戳；若分隔符恰在超时处分开，下一次读取仍可能包含多行，由缓存逐条解析。所有收到的片段先保存，退出时记录未完成半帧。缓冲溢出会报告 `BUFFER_GAP`。不会为了定时结束而改变串口超时，结束时可能多等待一次读取。

**诊断解析有意区别于导航定位校验**：四路各自检查，A1～A3 为 0、无效编码或格式错误时仍显示有效 A0；不计算坐标、不作高度补偿或滤波。A0 显示的是原始斜距（十六进制毫米换算成米）。单基站不能完成四基站定位。导航原有四路校验不变。

## 观察输出

- `RX b'...'`：实际收到的串口片段，保留 `\r\n` 等边界，便于观察乱码、分包和非 `mc` 报文。
- `A0=1.791m A1=INVALID(...) ...`：每个选定标签的 mc 帧；A1～A3 未开时无效属于预期现象。距离使用与导航相同的数值条件 `0 < mm < 0x7fffffff`，数值有效不等于测距准确。
- `duplicate=True`：与最近 64 个已识别帧 ID 重复，仍记录和显示；A0 新帧间隔只由非重复有效帧刷新。
- `no_signal_or_timeout`：底层空读，不等同于已经确认射频故障；结合 RX 判断串口输出状态。
- `other_tag`、`malformed_mc`、`line_too_long`：标签不符、字段布局异常、超过 4096 字节未遇到CRLF行尾。
- `$KT0` 等显示行单独归类为 `display_line`，保存并统计，不重复触发测距输出。
- `$RANGE_ERROR` 归类为 `range_error`，即使 `--quiet-raw` 也显示，摘要的 `device_range_errors` 单独计数；它不是串口读取异常。
- 每秒 `STATUS` 显示字节数、A0 数值有效帧数（含重复）、距离上次 A0 有效新帧的时间。

日志默认在 `logs/uwb_debug_20261014/时间戳/`（日志根目录遵循 `runtime.log_dir`）：

| 文件 | 内容 |
|---|---|
| `raw_uwb.jsonl` | 与导航相同的 SensorSample 结构，包括时间戳、序号、原始字节、空读和异常 |
| `uwb_diagnostics.jsonl` | 完整行、各路原始字段、距离、错误、重复标记及半帧/缓冲缺口事件 |
| `metadata.json` | 端口参数、标签、时长、采集链路 |
| `summary.json` | 总字节、A0 有效帧、重复、空读、读取错误、设备测距错误、显示行数、退出原因 |

支持 `--config`、`--port`、`--baudrate`、`--tag`、`--output-dir`。默认标签读取 `surface_navigation_20261010.uwb_tag`，缺省 `t0:0`。若终端输出过多，可添加 `--quiet-raw` 隐藏 RX 显示，原始日志照常保存。仅需现有 `PyYAML` 和实机采集用 `pyserial`，不需要 matplotlib。

没有信号时仍持续运行；串口读取异常会显示、记录并按原 worker 重试。发生读取错误或线程错误时最终退出码为 1；空读、无有效 A0 数据本身不会使程序非零退出，应结合摘要判断。
